# Vendored fonts

Both fonts are served from this folder so the portal renders with the network off.

| File | Font | Source | Licence |
| --- | --- | --- | --- |
| `jetbrains-mono-400.woff2`, `jetbrains-mono-700.woff2` | JetBrains Mono 2.304 | github.com/JetBrains/JetBrainsMono release zip, subset with `pyftsubset` to Latin, punctuation, arrows, box drawing and block elements (so ASCII/ANSI art lines up) | SIL OFL 1.1, `LICENSE-JetBrainsMono.txt` |
| `vt323-400.woff2` | VT323 | `@fontsource/vt323` 5.3.0 (latin subset) | SIL OFL 1.1, `LICENSE-VT323.txt` |
