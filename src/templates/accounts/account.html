how to use a token

a token lets a script act as you, with exactly your access: send it in the Authorization: Bearer <token> header of each request (it does not work in a browser address bar). no cookies or CSRF token are needed. revoke it here the moment you stop using it or it leaks; a revoked token gets 401 at once.
